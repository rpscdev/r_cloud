# Markdown Blog Posts

Add new posts as `.md` files with front matter:

```yaml
---
title: "Post title"
slug: "post-slug"
date: "2026-03-08"
description: "Short meta description"
image: "cover-image.jpg"
external_link: "https://example.com"
tags:
  - ai
  - mlops
---
```

Store images in `backend/content/images/` and reference by filename in `image`.
